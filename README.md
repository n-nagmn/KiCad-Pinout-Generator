# KiCad Pinout Generator

KiCadの基板データ（`.kicad_pcb`）から、2つの部品間の接続テーブル（ピンアサイン表）を抽出し、Markdown形式で出力するPythonスクリプトです。

変換基板やブレークアウトボードのドキュメント作成や、結線ミスの確認作業を自動化します。ネットリストを目視で書き写す手間を省くことができます。

## 特徴

* **依存ライブラリなし**
Pythonの標準ライブラリのみで動作します。`pip install` などで追加のパッケージをインストールする必要はありません。
* **あいまい検索（Fuzzy Match）対応**
長く複雑なフットプリント名をすべて入力する必要はありません。部品名の一部分（例: `USB` や `5767` など）を指定するだけで、対象の部品を検索・指定できます。
* **リファレンス番号なしでも動作**
インポートしたデータなどで、リファレンス番号（J1, CN1など）が割り当てられていない部品（`Unknown` や `REF**`）であっても、フットプリント名をIDとして自動的に認識し、処理できます。
* **Markdown形式で出力**
出力結果はMarkdownのテーブル形式になっているため、そのままGitHubのREADMEやドキュメントに貼り付けることができます。

## 動作環境

* Python 3.6 以上
* KiCad 6.0 / 7.0 / 8.0 のPCBファイル（S式フォーマット）

## 使い方

スクリプト `kicad_pinout.py` をダウンロードし、以下のコマンドで実行してください。

### 1. コンポーネント一覧の表示

まずは、PCBファイル内にどのような部品（ID）として認識されているかを確認します。

```bash
python kicad_pinout.py your_board.kicad_pcb -l

```

**出力例:**

```text
--- Components in your_board.kicad_pcb ---
Ref / ID                                 Pads  
--------------------------------------------------
J1                                       38    
J2                                       160   
TE_5767007-8:TE_5767007-8                43
SAMTEC_ASP-122952-01:SAMTEC_ASP...       172   
--------------------------------------------------

```

### 2. ピンアサイン表の生成

接続元（`-a`）と接続先（`-b`）の部品を指定してテーブルを生成します。
指定には「リファレンス番号（J1など）」または「部品名の一部（あいまい検索）」が使用できます。

**コマンド例:**

リファレンス番号で指定する場合:

```bash
python kicad_pinout.py your_board.kicad_pcb -a J1 -b J2

```

部品名の一部で指定する場合（リファレンスがない場合に便利）:

```bash
python kicad_pinout.py your_board.kicad_pcb -a 5767 -b ASP

```

**出力結果:**

```markdown
Generating Pinout: TE_5767007-8... <--> SAMTEC_ASP...

| TE_5767007-8 Pin | Net Name | SAMTEC_ASP Pin |
| :--- | :--- | :--- |
| 1 | HSM_CLKOUT0 | 39 |
| 2 | HSM_CLKIN0 | 40 |
| 3 | HSM_D0 | 41 |
...

```
